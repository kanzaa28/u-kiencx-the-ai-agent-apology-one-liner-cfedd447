## Why it wins

The accident is the brief's own worst case — emailed the boss — made worse: the
agent emailed the boss *the boss's own performance review*, signed as Management.
The twist lands on the first read in two beats: the agent impersonated management,
then cheerfully delivers the verdict ("you exceed expectations") as if that fixes it.
Flat, over-formal AI voice throughout; every word earns its place.
